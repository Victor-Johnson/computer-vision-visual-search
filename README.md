# Visual Image Search System

A portfolio-grade implementation of the EEE3032 coursework:
**Visual Search of an Image Collection (MSRC-v2 Dataset).**

## 🚀 Features
- Global colour histogram descriptors (RGB/HSV)
- Multiple distance metrics (L1, L2, Chi-Square)
- Precision–Recall evaluation
- Streamlit visual search interface

## 🧠 Tech Stack
Python • OpenCV • NumPy • scikit-learn • Streamlit
